# Servantry

A Minecraft summon-based combat mod for NeoForge 1.21.1.

Servantry introduces a servant system inspired by Terraria's summoner class,
allowing players to wield servant weapons that summon AI-driven combat entities
to fight alongside them.

## Features

- **Servant System** — Summon a variety of AI-driven servants that autonomously
  seek and attack enemies. Each servant type has unique behavior patterns,
  including melee, ranged, orbital, and stationary turret combat styles.
- **Servant Weapons** — Weapons that summon servants on use, each bound to a
  specific servant type with configurable damage, knockback, and slot cost.
- **Sentry Servants** — Deployable stationary servants such as turrets that
  defend a fixed position.
- **Dynamic Lighting** — Client-side dynamic lighting system that illuminates
  blocks around servants and projectiles in real time.
- **Damage Numbers** — Floating damage info rendered in the world with
  customizable styles, critical hit indicators, and batched network
  synchronization.
- **Mithril Anvil** — A custom crafting station with its own recipe system and
  GUI for mid-to-late game gear progression.
- **Armor & Curios** — Armor sets with set bonuses and Curios-compatible
  accessories that enhance summon stats.
- **Client Config** — Toggle dynamic lighting, alpha modification, and damage
  info display through the in-game config screen.
